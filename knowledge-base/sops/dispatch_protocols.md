# Standard Operating Procedures — Dispatch Protocols
## Category: SOPs | Audience: 911 Dispatcher | Effective: 2026

---

## Medical Emergency — Dispatch Protocol

### Cardiac Arrest
1. Dispatch: 2× ALS ambulance + 1× fire engine (AED support)
2. Priority 1 (lights and siren)
3. Hospital pre-alert: nearest cardiac-capable hospital, flag "cardiac arrest inbound"
4. Keep caller on line — CPR instructions via medical protocol card
5. Notify supervisor if response > 4 minutes

### Chest Pain / Suspected Cardiac
1. Dispatch: 1× ALS ambulance
2. Priority 1
3. Hospital pre-alert: nearest hospital with cardiac_cath, flag "chest pain, ALS en route"
4. If caller reports LOC or collapse: upgrade to 2× ALS + fire

### Stroke Symptoms (FAST positive)
1. Dispatch: 1× ALS ambulance
2. Priority 1 — time critical (stroke window is 3–4.5 hours)
3. Hospital pre-alert: nearest hospital with stroke_team, include "last known well" time
4. Do NOT delay dispatch to gather more information

### Unconscious Person
1. Dispatch: 1× ALS ambulance
2. Priority 1
3. Confirm breathing status from caller immediately
4. If not breathing: 2× ALS + fire engine, Priority 1, cardiac arrest protocol
5. Hospital pre-alert: nearest Level 1 trauma if trauma suspected; nearest ALS-receiving if medical

### Overdose
1. Dispatch: 1× ALS ambulance
2. Priority 1
3. Ask caller: "Is Narcan available?" — if yes, guide caller to administer per protocol card
4. If unresponsive and not breathing: 2× ALS + fire, cardiac arrest protocol

### Seizure
1. Dispatch: 1× ALS ambulance
2. Priority 2 (unless prolonged > 5 min → Priority 1)
3. Tell caller: keep patient safe from injury, do not restrain, do not put anything in mouth
4. Upgrade to Priority 1 if: first seizure ever, post-ictal unresponsive > 5 min, known cardiac history

### Difficulty Breathing
1. Dispatch: 1× ALS ambulance
2. Priority 1 if severe (cannot speak in full sentences, cyanotic)
3. Priority 2 if mild (speaking normally, history of asthma)
4. Hospital pre-alert if severe: flag "respiratory distress"

## Trauma — Dispatch Protocol

### Motor Vehicle Collision (MVC)
| Severity | Units | Priority |
|----------|-------|----------|
| Minor — no injuries reported | 1× police | 3 |
| Injuries reported | 1× ALS + 1× police | 2 |
| Entrapment | 2× ALS + 2× fire engines + rescue unit | 1 |
| Rollover / ejection | 2× ALS + 2× fire + police | 1 |
| Multi-vehicle (5+) | MCI protocol — see below | 1 |

- Hospital pre-alert for ALS calls: nearest Level 1 trauma if mechanism is high-energy
- Police needed for all collisions (traffic management, report)

### Gunshot Wound (GSW)
1. Dispatch: 2× ALS + 2× police units
2. Priority 1
3. Stage ALS units until police confirm scene safe
4. Hospital pre-alert: nearest Level 1 trauma, flag "GSW inbound, ALS en route"
5. Notify supervisor and shift commander

### Stabbing
1. Dispatch: 1× ALS + 2× police
2. Priority 1
3. Stage ALS until scene safe
4. Hospital pre-alert: nearest Level 1 trauma if torso/neck involved
5. BLS acceptable if wound to extremity only

### Fall from Height
- Under 10 feet: 1× BLS or ALS depending on symptoms
- Over 10 feet: 1× ALS + Priority 1, suspect spinal injury
- Construction / industrial fall: ALS + fire + safety inspector notify

## Fire — Dispatch Protocol

### Structure Fire (confirmed)
1. Dispatch: 2× fire engines + 1× ladder truck + 1× ALS ambulance + 1× supervisor
2. Priority 1
3. Notify all units of address and building type (residential vs commercial)
4. Request mutual aid if: high-rise, large commercial, multiple alarms reported
5. Gas utility company notify if structure fire adjacent to gas lines

### Vehicle Fire
1. Dispatch: 1× fire engine
2. Priority 2
3. Add ALS if injuries or occupants trapped
4. Notify police if blocking roadway

### Brush / Wildland Fire
1. Dispatch: wildland fire engine units (Type 3 or Type 4 engines)
2. Priority 1 if near structures
3. Notify Cal Fire mutual aid if moving toward structures
4. Evacuate caller if fire advancing

## Hazmat — Dispatch Protocol

### Chemical Spill / Toxic Release
1. Dispatch: 1× hazmat unit + 2× fire engines + 1× ALS ambulance
2. Priority 1
3. Establish perimeter per ERG isolation distances (see hazmat guide)
4. Advise callers in isolation zone: evacuate or shelter-in-place per wind direction
5. Notify: hazmat incident commander, public health if large release

### Gas Leak — Natural Gas
1. Dispatch: 1× fire engine
2. Priority 2 (Priority 1 if explosion risk or injuries)
3. Contact gas utility company immediately
4. Evacuate if leak indoors

### Carbon Monoxide Alarm / Symptoms
1. Dispatch: 1× fire engine (CO monitoring equipment)
2. Priority 2 (Priority 1 if anyone unconscious)
3. Add ALS if symptoms reported (headache, nausea, dizziness, unconscious)
4. Evacuate building

## Mass Casualty Incident (MCI) Protocol

**Trigger:** 5+ patients, OR dispatcher anticipates multi-unit medical response

### Immediate Actions
1. Declare MCI — notify supervisor and shift commander
2. Dispatch: all available ALS units + fire engines
3. Establish command post (safe staging area away from incident)
4. Distribute patients across hospitals — do not send all to one facility
5. Notify hospital system: "MCI declared, expect [X] patients, ETA [Y] minutes"
6. Request mutual aid from neighboring dispatch centers

### Patient Distribution (5–10 patients)
- 40% to nearest Level 1 trauma
- 30% to second Level 1 or Level 2
- 30% to remaining hospitals with capacity

## Crime — Dispatch Protocol

### Active Shooter / Weapons
1. Dispatch: all available police units + ALS (stage away from scene)
2. Priority 1
3. Keep caller quiet and on line — "Do not speak loudly. Can you text me your location?"
4. Do NOT send medical units until police clear scene
5. Notify: SWAT if hostages, FBI if federal involvement suspected
6. Hospital pre-alert: multiple trauma bays, notify of potential MCI

### Armed Robbery in Progress
1. Dispatch: 2× police units
2. Priority 1
3. Keep caller on line silently if possible

### Domestic Violence
1. Dispatch: 2× police units
2. Priority 2 (Priority 1 if weapon involved or injury reported)
3. Add ALS if injuries
4. Do not reveal caller is on phone if dangerous to do so

---

## General Dispatcher Rules

1. **Location first, always** — get the address before any other question
2. **Stay on the call** — do not disconnect until units arrive unless caller requests
3. **Document everything** — all decisions entered in CAD in real time
4. **Escalate without hesitation** — notify supervisor for any: MCI, officer down, major hazmat, media-visible incidents
5. **Approval required for all dispatches** — ARIA recommendations must be reviewed and approved before dispatch logged
